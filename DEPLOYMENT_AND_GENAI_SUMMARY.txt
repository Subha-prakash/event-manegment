--- QUESTION 1: DESCRIBE THE CHANGES/UPDATES MADE IN THE DEPLOYED VERSION ---
[Word Count: ~500 words | Strictly under 1024 words]

The deployed version of EventGenie AI represents a production-grade, end-to-end full-stack web platform built to automate and elevate event planning across weddings, corporate conferences, birthdays, collegiate fests, and cultural celebrations. The application bridges generative artificial intelligence with deterministic financial modeling and real-time logistics tracking.

A. FRONTEND ARCHITECTURE AND USER EXPERIENCE:
The user interface is engineered with React 18, Vite, TypeScript, and Tailwind CSS, featuring an elegant modern SaaS visual style with soft indigo and purple accents, glassmorphism cards, responsive layouts, and accessible typography. All twelve required functional pages have been completely implemented:
1. Landing Page: Showcases product capabilities with a live, interactive budget and guest estimator slider, animated feature grid, and instant test-drive pathways.
2. Authentication & Demo System: Offers email/password authentication alongside a 1-click demo login option pre-loaded as planner Priya Sharma.
3. Real-Time Event Day Dashboard: Incorporates a live countdown timer (Days, Hours, Minutes, Seconds), key summary cards for remaining budget, completed milestones, confirmed vendors, and RSVP headcounts, paired with interactive Recharts expense charts and urgent overspending alerts.
4. AI Event Creation Wizard: A four-step guided flow capturing event names, categories, multi-day schedules, location, headcount, budgets, currencies, venue styles, food preferences, cultural rituals, and formality levels, concluding with celebratory confetti.
5. AI Master Plan Page: Displays the ten-part generated event plan with inline editing and on-demand section regeneration allowing targeted updates without overwriting untouched sections.
6. AI Budget Manager: Provides a deterministic financial calculator tracking Estimated, Quoted, and Actual expenses separately. Includes category-wise Recharts donut and comparative bar charts, overspending alerts, AI cost-reduction advice, and multi-currency support (defaulting to INR with Indian Lakhs formatting).
7. Smart Timeline & Tasks: Generates milestone-driven schedules (T-90d down to Event Day) with priority filters (High, Medium, Low), status toggles (Not Started, In Progress, Completed), and live progress bars.
8. Vendor Management Hub: Manages nine distinct service categories (Venues, Caterers, Decorators, Photographers, DJs, Stylists, Logistics, Equipment, Coordinators), tracking quotations, agreed pricing, advance payments, balance due calculations, and missing service checklists.
9. Guest List & RSVP Manager: Tracks guest affiliations (Family, Friends, VIP, Colleagues), plus-one additions, dietary requirements, and offers one-click browser CSV export.
10. Context-Aware AI Chat Assistant: Conversational co-pilot referencing live active event parameters and generating structured Action Proposals requiring user confirmation before database changes occur.
11. Ideas & Inspiration Library: Categorized ideas repository for DIY decor, party activities, return gifts, and invitation wording with individual cost estimations.
12. Event Settings & AI Control Center: Facilitates event parameter modification, runtime Gemini API key configuration and testing, full JSON blueprint export, and secure event deletion.

B. BACKEND API, PERSISTENCE, AND VERCEL CLOUD DEPLOYMENT:
The backend is powered by Node.js and Express with Zod input validation. A dual-mode database engine provides file-backed persistence locally and adapts to Vercel Serverless environments via /tmp storage with in-memory fallbacks. A dedicated vercel.json and api/index.js serverless adapter route API requests into serverless functions, and a complete PostgreSQL schema (supabase_schema.sql) with Row Level Security (RLS) is included for cloud database migrations.

A. GEN AI MODEL, SDK, AND CORE ARCHITECTURE:
EventGenie AI is powered by the Google Gemini API, specifically utilizing the flagship Gemini 3.8 Flash model (gemini-3.8-flash) via the official @google/genai SDK (version >= 2.3.0). All generative outputs are enforced via structured JSON schemas (responseMimeType: 'application/json') with backend Zod validation to ensure predictable data formatting.

The platform employs a robust Dual-Engine Architecture:
1. Live Gemini Mode: Connects directly to Google Gemini 3.8 Flash whenever an API key is supplied via environment variables or runtime settings.
2. Built-in Domain Engine: When an external key is absent, an offline planning engine generates structured event plans, deterministic budgets, and localized suggestions, ensuring full functionality and zero downtime.

B. APPLICATION AREAS WHERE GENERATIVE AI IS UTILIZED:

1. AI Event Creation Wizard (/create-event -> POST /api/ai/generate-plan):
When a user submits an event vision, Gemini 3.8 Flash synthesizes a tailored 10-section master plan:
- Creative Concept and Theme: Generates a bespoke theme narrative harmonizing decor, ambiance, and location.
- Decoration Blueprint: Recommends specific aesthetic concepts for entrances, focal backdrops, ambient lighting, and tables.
- Venue Specifications: Formulates square footage, power backup requirements, climate needs, and parking capacities.
- Culinary & Catering Menu: Designs multi-course dining experiences aligned with dietary restrictions (e.g. Jain, Vegan, Regional).
- Entertainment Program: Structures musical pacing, live performances, and cultural rituals.
- Guest Hospitality Logistics: Recommends arrival protocols, digital RSVPs, and accessibility plans.
- Vendor Checklist: Pinpoints required service professionals.
- Budget Allocation: Distributes the total budget realistically across categories.
- 90-Day Timeline: Establishes chronological milestone deadlines pegged to the event date.
- Essential Reminders: Flags licensing deadlines and local noise curfews.

2. On-Demand Section Regenerator (/plan -> POST /api/ai/regenerate-section):
Users can selectively re-prompt Gemini to regenerate individual sections (such as Decor, Catering, or Timeline) using custom instructions (e.g., 'Make floral arrangements minimalist using local marigolds') without disturbing other saved sections.

3. Personalized Ideas & Inspiration Library (/ideas -> POST /api/ai/generate-ideas):
Gemini generates creative, budget-conscious ideas across DIY decor, guest favors, party games, invitation copy, and zero-waste celebrations, each accompanied by realistic cost estimations.

4. Context-Aware Conversational Planning Assistant (/chat -> POST /api/ai/chat):
The chat assistant loads the active event context (budget ceiling, guest count, location, confirmed vendors). It handles complex queries like 'Reduce decoration costs by 20%' or 'Suggest a kids party for 15 under 5000', explaining mathematical trade-offs and presenting structured Action Proposals that require explicit user approval before updating records.

C. SAFETY AND ARITHMETIC INTEGRITY:
Mathematical arithmetic (totals, balances, utilization percentages) is deliberately handled by deterministic application code rather than language models, preventing hallucinations and ensuring audit-ready accuracy.
